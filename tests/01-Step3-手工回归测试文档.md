# `new_stock` Step 3 手工回归测试文档

## 1. 文档目标
本测试文档面向测试工程师，用于在 `Step 3` 范围内对主窗口、设置窗口、本地闭环、板块构建和输入稳定性做手工回归。

当前版本必须先通过“主窗口可见且非白屏”这一阻断项，才允许继续执行后续测试。

---

## 2. 本轮最高优先级阻断项

### 2.1 主窗口白屏回归
必须优先验证：
- `cargo run` 后主窗口成功拉起
- 窗口标题显示为 `new_stock`
- 主窗口不是整窗白屏
- 顶部工具栏、四大指数、左侧双列、主图区、笔记区、底部状态栏都可见

若出现以下任一现象，本轮 `Step 3` 直接判定 **未完成**：
- 窗口启动后整窗白屏
- 只有空白背景，没有任何 UI 骨架
- 主窗口只显示标题栏，不显示内容区
- UI 未渲染完成，无法继续点击指数 / 板块 / 个股

说明：
- 本问题曾真实出现，根因是 `Svelte 5` 入口仍使用旧式组件实例化挂载方式，导致窗口进程正常但前端未正确挂载。
- 本轮修复后，测试必须把“白屏不再复现”作为第一条回归结论明确记录。

建议记录：
- 是否白屏：`是 / 否`
- 首屏是否完整渲染：`是 / 否`
- 是否可继续执行后续用例：`是 / 否`
- 截图路径

## 5. Step 3 主流程回归

### 5.1 主窗口基础渲染
验证项：
- 顶部工具栏可见
- 四大指数切换区可见
- 左侧板块列可见
- 中间成分股列可见
- 主图区可见
- 笔记区可见
- 底部状态栏可见

通过标准：
- 页面结构与旧版 UI 设计一致
- 没有明显布局塌陷或区域缺失

### 5.2 指数 / 板块 / 个股切图
验证项：
- 点击四大指数，主图区切到对应目标
- 点击左侧板块，主图区切到板块图
- 点击成分股，主图区切到个股图

通过标准：
- 每次切图都有明确反馈
- 不出现整页刷新
- 不出现白屏、闪屏、卡死

### 5.3 日 K / 周 K 切换
验证项：
- 点击 `日K`
- 点击 `周K`
- 多次来回切换

通过标准：
- 主图区正常切换
- 图表区不出现空白残留
- 不因切换导致整页重建

### 5.4 设置窗口独立打开
验证项：
- 点击设置按钮
- 独立设置窗口打开
- 主窗口仍保持原状态

通过标准：
- 设置窗口不是主窗口内 modal
- 主窗口内容不被重置
- 来回切换窗口不会触发主窗口白屏

### 5.5 笔记保存与恢复
验证项：
- 在笔记区输入内容
- 点击保存
- 切换目标后再切回

通过标准：
- 输入过程中不丢焦点
- 保存后内容可恢复
- 不因状态更新导致输入中断

### 5.6 板块创建联动
验证项：
- 在设置窗口新建板块
- 分别观察快路径与后台构建路径
- 创建后主窗口目录刷新

通过标准：
- 新板块可见
- 主窗口不白屏
- 主窗口不整页重载
- 板块构建中状态可见

### 5.7 输入稳定性
重点验证：
- 设置窗口输入 `App Key / App Secret / Access Token`
- 板块名称输入
- 板块成员输入
- 主窗口笔记输入

通过标准：
- 输入过程中不失焦
- 不因后台状态变化而被覆盖
- 不因跨窗口同步而中断

## 6. 本轮新增回归要求

### 6.1 白屏修复专项回归
本轮必须新增以下回归动作：
- 连续启动应用 `3` 次，确认不再随机白屏
- 启动后立即点击指数、板块、设置，确认不会在首屏初始化后变白
- 打开设置窗口再返回主窗口，确认主窗口内容仍完整

通过标准：
- `3` 次启动都能完整显示 UI
- 不出现“进程正常、窗口存在、内容区为空白”的情况

### 6.2 窗口挂载修复后的回归观察点
本轮白屏修复后，测试需额外观察：
- 主窗口是否在启动后立即渲染
- 设置窗口是否也能稳定渲染
- 是否只修好了主窗口，但设置窗口仍空白

---

## 7. 失败判定
出现以下任一情况，直接判定本轮 `Step 3` 未通过：
- 主窗口白屏
- 主窗口基础布局缺失
- 无法继续执行切图
- 设置窗口无法正常打开
- 输入框一输入就失焦
- 新建板块导致主窗口不可操作
